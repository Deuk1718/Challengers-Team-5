# 기능별 수용 기준 (Acceptance Criteria) 체크리스트

> 작성일: 2026-03-31
> 기준 문서: `10-prd-final.md` 5.2절 기능 상세 명세
> 목적: PRD에 정의된 모든 수용 기준(AC) 항목을 추적 및 검증

---

## 사용 방법

- 각 기능 구현 후 해당 섹션의 체크리스트를 검증한다
- 검증 완료 시 체크박스를 체크하고 검증일과 담당자를 기입한다
- 미달 항목은 수정 후 재검증한다

## F-01 | 매칭 스코어 카드

> 연결 기회: O1 | 우선순위: P0

| # | 수용 기준 | 검증 방법 | 상태 | 검증일 |
|---|---------|---------|------|-------|
| AC1 | 스코어 0~100 범위로 계산되어 카드에 표시된다 | 다양한 프로필/공고 조합으로 점수 범위 확인 | ⬜ | - |
| AC2 | 일치 스킬은 초록, 부족 스킬은 빨간 배지로 구분된다 | 시각적 확인 + 색상 대비 검증 | ⬜ | - |
| AC3 | 신규 공고 등 스코어 없는 경우 배지 없이 정상 표시된다 | `candidateScore` 없는 공고 카드 렌더링 확인 | ⬜ | - |
| AC4 | 모바일(< 768px)에서 게이지 바가 정상 렌더링된다 | 360px 뷰포트에서 게이지 바 확인 | ⬜ | - |
| AC5 | (A/B E1) A 변형: 숫자만 표시 ("82%") | abVariant='A' 카드 확인 | ⬜ | - |
| AC6 | (A/B E1) B 변형: 게이지 바 + 스킬 일치/불일치 배지 표시 | abVariant='B' 카드 확인 | ⬜ | - |

## F-03 | 지원 전 역량 리포트 + AI 탈락 사유 시뮬레이션

> 연결 기회: O2, O5 | 우선순위: P0

| # | 수용 기준 | 검증 방법 | 상태 | 검증일 |
|---|---------|---------|------|-------|
| AC1 | 역량 리포트가 지원 버튼 클릭 시 1초 이내에 로드된다 | 브라우저 Network 탭에서 응답 시간 확인 | ⬜ | - |
| AC2 | 합격자 평균 데이터 미보유 공고는 "데이터 수집 중" 안내를 표시한다 | 해당 공고 ID로 접근하여 안내 메시지 확인 | ⬜ | - |
| AC3 | AI 시뮬레이션 결과가 공고 JD의 요구사항 키워드와 이력서를 비교하여 생성된다 | Mock 응답에 JD 키워드 포함 여부 확인 | ⬜ | - |
| AC4 | 리포트 확인 후 지원 완료 시 `viewed_report=true` 이벤트가 기록된다 | 브라우저 콘솔에서 `apply_complete` 이벤트 + `viewed_report: true` 확인 | ⬜ | - |
| AC5 | AI 시뮬레이션 결과에 "AI 추정 결과" 면책 레이블이 명시된다 | 화면에서 면책 문구 존재 확인 | ⬜ | - |
| AC6 | 사이드 패널 접근성 — ESC 키로 닫기 가능 | 키보드 ESC 키 테스트 | ⬜ | - |
| AC7 | 사이드 패널 접근성 — 포커스 트랩 동작 | Tab 키가 패널 내부에서만 순환하는지 확인 | ⬜ | - |

## F-04 | 포트폴리오 프로젝트 태그 입력

> 연결 기회: O4 | 우선순위: P1

| # | 수용 기준 | 검증 방법 | 상태 | 검증일 |
|---|---------|---------|------|-------|
| AC1 | 프로젝트 카드 1개 이상 등록 시 매칭 스코어가 미등록 대비 변경된다 | 동일 공고에 카드 등록 전/후 스코어 비교 | ⬜ | - |
| AC2 | 역할 "리드" 선택 시 경력 복잡도 점수에 가산이 적용된다 | 역할 "리드"로 카드 등록 후 스코어 상승 확인 | ⬜ | - |
| AC3 | 카드 등록/수정/삭제가 모두 가능하다 | 3개 작업 각각 수행 후 UI 반영 확인 | ⬜ | - |
| AC4 | 최대 5개 제한 — 5개 이후 추가 버튼 비활성화된다 | 5개 등록 후 추가 버튼 상태 확인 | ⬜ | - |

## F-05 | 조직문화 핏 태그 시스템

> 연결 기회: O3 | 우선순위: P1

| # | 수용 기준 | 검증 방법 | 상태 | 검증일 |
|---|---------|---------|------|-------|
| AC1 | 태그 없는 공고도 공고 상세 정상 표시 (태그 섹션만 비표시) | 문화 태그 없는 공고 상세 페이지 확인 | ⬜ | - |
| AC2 | 문화 태그 필터 선택 시 해당 태그 보유 공고만 노출된다 | "빠른 의사결정" 태그 필터 후 해당 공고만 노출 확인 | ⬜ | - |
| AC3 | 태그 클릭 시 재직자 평점 요약이 툴팁으로 표시된다 | 마우스오버/포커스 시 툴팁 확인 | ⬜ | - |
| AC4 | 평점 없는 태그는 평점 UI 없이 태그만 표시된다 | `rating: null` 태그 확인 | ⬜ | - |

## F-06 | 자격요건 자동 필터링 + Skill-Fit Score (기업용)

> 연결 기회: 신1-2 | 우선순위: P1

| # | 수용 기준 | 검증 방법 | 상태 | 검증일 |
|---|---------|---------|------|-------|
| AC1 | 필수 조건 설정: 최소 경력(년), 필수 스킬(복수), 자격증(텍스트) 3종 이상 지원 | 기업 대시보드에서 3가지 조건 설정 가능 확인 | ⬜ | - |
| AC2 | 자동 분류 정확도: 테스트 기준 `적합/미충족` 판별 일치율 95% 이상 | Mock 데이터 20건 분류 결과와 수동 판별 비교 | ⬜ | - |
| AC3 | Skill-Fit Score가 근거 요약과 함께 표시된다 | 점수 + 근거 요약 텍스트 표시 확인 | ⬜ | - |
| AC4 | HR이 조건 미충족 지원자를 수동 `적합` 재분류할 수 있다 | 미충족 지원자 재분류 버튼 클릭 후 탭 이동 확인 | ⬜ | - |
| AC5 | 각 분류 탭에 지원자 수가 표시된다 | 탭 레이블에 수 표시 ("적합 후보 (8)") 확인 | ⬜ | - |
