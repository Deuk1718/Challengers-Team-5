## 1. 디자인 원칙

| 원칙 | 설명 | 적용 예시 |
|-----|------|---------|
| **정보 밀도 우선** | 클릭 전 판단에 필요한 정보를 카드 레벨에서 노출 | 매칭 스코어·스킬 배지가 카드에 바로 보임 |
| **보완 방향 중심** | 부정적 결과도 "다음 행동"과 함께 제시 | 부족 스킬 옆에 보완 방법 표시 |
| **양면 시장 명확 분리** | 구직자/기업 경험을 완전히 분리된 플로우로 설계 | `/jobs` vs `/employer` 완전 독립 |
| **점진적 공개** | 핵심 정보를 먼저, 상세는 사이드 패널·토글로 | 역량 리포트는 사이드 패널 |
| **신뢰 표시** | AI 생성 결과에 반드시 출처 레이블 | "AI 추정 결과" 뱃지 |

## 8. 접근성 (A11y) 명세

### 8.1 시맨틱 HTML 구조

| 페이지 | 구조 |
|-------|------|
| 모든 페이지 | `<header>` → `<nav>` → `<main>` → `<footer>` |
| 공고 목록 | `<section>` > `<aside>` (필터) + `<ul>` > `<li>` > `<article>` |
| 공고 상세 | `<article>` (본문) + `<aside>` (리포트 패널) |
| 프로필 | `<section>` × 3 (기본정보, 진단, 프로젝트) |
| 기업 대시보드 | `<section>` > 탭 UI + `<ul>` > `<li>` (지원자 목록) |

### 8.2 ARIA 속성

| 컴포넌트 | ARIA |
|---------|------|
| 게이지 바 | `role="progressbar"`, `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"`, `aria-label` |
| 스킬 배지 | `aria-label="React 일치"` 또는 `aria-label="AWS 부족"` |
| 사이드 패널 | `role="dialog"`, `aria-modal="true"`, `aria-labelledby` |
| 필터 패널 | `role="group"`, `aria-label="필터"` |
| 문화 태그 툴팁 | `role="tooltip"`, `aria-describedby` |
| 탭 | `role="tablist"`, `role="tab"`, `aria-selected`, `role="tabpanel"` |
| 레벨 불일치 | `role="alert"` (동적 삽입 시) |

### 8.3 키보드 내비게이션

| 요소 | 키 | 동작 |
|-----|-----|------|
| 카드 | `Enter` / `Space` | 공고 상세로 이동 |
| 필터 칩 | `Enter` / `Space` | 필터 토글 |
| 사이드 패널 | `Escape` | 패널 닫기 |
| 사이드 패널 내부 | `Tab` | 포커스 트랩 (패널 밖으로 나가지 않음) |
| 탭 | `←` `→` | 탭 전환 |
| 모달 | `Escape` | 모달 닫기 |

### 8.4 스크린 리더 고려

- 게이지 바: "매칭 스코어 82퍼센트" 읽힘
- 스킬 배지: "React 일치", "AWS 부족" 읽힘
- 레벨 태그: "주니어 레벨" 읽힘
- AI 레이블: "AI 추정 결과" → 이후 본문이 연결됨
- 이미지: `alt` 텍스트 필수, 장식 이미지는 `alt=""` + `aria-hidden="true"`
