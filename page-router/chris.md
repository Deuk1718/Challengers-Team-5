────────────────────────────────
4. 서비스 구조
────────────────────────────────

전체 서비스는 10개의 핵심 화면으로 구성됩니다.

--------------------------------
[페이지 라우터 설계]
--------------------------------

| # | 경로 | 화면명 | 역할 |
|---|------|--------|------|
| 1 | `/` | 랜딩 페이지 | 서비스 가치 소개, 구직자·기업 CTA 분기, 비로그인 진입점 |
| 2 | `/onboarding` | 온보딩 | 회원 유형 선택(구직자/기업), 초기 프로필·공고 기본 정보 설정 |
| 3 | `/jobs` | 공고 탐색 | 매칭 스코어 카드(F-01), 경력 레벨 태그·필터(F-02), 문화 핏 필터(F-05) |
| 4 | `/jobs/:id` | 공고 상세 | 문화 태그 표시(F-05), 역량 리포트 사이드 패널(F-03), 지원하기 진입 |
| 5 | `/profile` | 구직자 프로필 | 프로젝트 카드(F-04), 역량 진단(F-15), 이력서 개선 가이드(F-16) |
| 6 | `/apply` | 지원 현황 | 지원 공고 목록·상태 추적, 저장 공고 관리, 리포트 확인 이력 |
| 7 | `/employer` | 기업 대시보드 | 지원자 자동 분류(F-06), Skill-Fit Score, 리스크 포인트(F-17) |
| 8 | `/employer/post` | 공고 등록·관리 | 공고 작성, 문화 태그 설정(F-05), 필수 자격요건 조건 설정(F-06) |
| 9 | `/employer/candidates/:id` | 지원자 상세 | Skill-Fit 근거 상세, 리스크 포인트 확인·처리, 면접 초대 액션 |
| 10 | `/auth` | 로그인/회원가입 | 사용자 인증 및 개인 데이터 연결 |

--------------------------------

각 화면의 역할은 다음과 같습니다.

1. 랜딩 페이지
- 가장 자주 사용하는 핵심 화면
- 구직자·기업 양면 유저를 대상으로 서비스 핵심 가치 전달
- 전체 흐름의 허브이자 전환 CTA 시작점

2. 공고 탐색 (`/jobs`)
- 핵심 행동(공고 탐색)을 수행하는 화면
- 매칭 스코어 카드·레벨 태그·문화 핏 필터로 사용자 가치가 직접 발생하는 지점

3. 공고 상세 (`/jobs/:id`)
- 지원 결정의 최종 판단 화면
- 역량 리포트 사이드 패널과 AI 탈락 시뮬레이션으로 차별화 기능 집중

4. 구직자 프로필 (`/profile`)
- 매칭 정확도를 높이는 데이터 입력 허브
- 역량 진단·이력서 개선이 연결되어 추천 품질과 직결됨

5. 지원 현황 (`/apply`)
- 구직자의 활동 이력 및 상태 추적 화면
- 저장 공고·리포트 확인 이력을 통해 재방문 동기 제공

6. 온보딩 (`/onboarding`)
- 신규 가입 직후 유일하게 통과하는 분기 화면
- 구직자/기업 역할을 확정하고 초기 데이터를 수집하여 추천 품질 기반 형성

7. 기업 대시보드 (`/employer`)
- 기업 HR·팀장의 핵심 업무 화면
- 지원자 자동 분류·Skill-Fit Score·리스크 포인트를 한 화면에서 처리

8. 공고 등록·관리 (`/employer/post`)
- 기업 측 데이터 입력 허브
- 문화 태그·필수 조건 설정이 구직자 매칭 알고리즘에 직접 반영됨

9. 지원자 상세 (`/employer/candidates/:id`)
- 기업 사용자가 채용 의사결정을 내리는 최종 화면
- Skill-Fit 근거 상세와 리스크 포인트 확인·면접 초대 액션 집중

10. 로그인/회원가입 (`/auth`)
- 사용자 식별 및 데이터 연결
- 개인화 기능 활성화 진입점

--------------------------------

서비스 흐름은 다음과 같이 구성됩니다.

**구직자 흐름**
"랜딩 CTA → 회원가입(/auth) → 온보딩(역할·프로필 초기 설정) → 공고 탐색(매칭 스코어 확인) → 공고 상세(역량 리포트 열람) → 지원 완료 → 지원 현황 추적"

**기업 흐름**
"랜딩 CTA → 회원가입(/auth) → 온보딩(기업 정보·공고 초안) → 공고 등록(문화 태그·필수조건 설정) → 기업 대시보드(지원자 자동 분류 확인) → 지원자 상세(Skill-Fit·리스크 검토) → 면접 초대"
