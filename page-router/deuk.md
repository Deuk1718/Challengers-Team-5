전체 서비스는 10개의 핵심 화면으로 구성됩니다.                                                     
                                                                                                     
  ---[페이지 라우터 설계]                                                                            
                                                                                                     
  ┌─────┬──────────────────────────┬─────────────────┬────────────────────────────────────────────┐  
  │  #  │           경로           │     화면명      │                    역할                    │
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤  
  │ 1   │ /                        │ 랜딩            │ 서비스 소개 + 구직자/기업 CTA 분기 진입점  │
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤  
  │ 2   │ /jobs                    │ 공고 탐색       │ 매칭 스코어 카드(F-01) + 레벨 태그(F-02) + │  
  │     │                          │                 │  문화 태그 필터(F-05)로 공고 탐색          │  
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤  
  │ 3   │ /jobs/:id                │ 공고 상세       │ 역량 리포트 + AI 탈락 시뮬레이션(F-03) +   │  
  │     │                          │                 │ 문화 태그 표시(F-05) + 지원 액션           │  
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤
  │ 4   │ /profile                 │ 구직자 프로필   │ 프로젝트 카드 입력(F-04) + 역량 진단(F-15) │  
  │     │                          │                 │  + 이력서 개선 가이드(F-16)                │  
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤
  │ 5   │ /mypage                  │ 마이페이지      │ 지원 현황 추적 + 저장한 공고 + AI 진단     │  
  │     │                          │                 │ 이력 열람                                  │  
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤
  │ 6   │ /onboarding              │ 초기 설정       │ 역할 선택(구직자/기업) + 기본 정보 입력 +  │  
  │     │                          │                 │ 목표 직무/회사 정보 설정                   │
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤  
  │ 7   │ /employer                │ 기업 대시보드   │ 자격요건 자동 필터링 + Skill-Fit           │  
  │     │                          │                 │ Score(F-06) + 리스크 포인트(F-17)          │
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤  
  │ 8   │ /employer/post           │ 공고 등록       │ JD 작성 + 필수 조건 설정 + 문화 핏 태그    │  
  │     │                          │                 │ 선택(F-05)                                 │
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤  
  │ 9   │ /employer/candidates/:id │ 지원자 상세     │ Skill-Fit 분석 상세 + 리스크 포인트        │
  │     │                          │                 │ 확인/처리(F-17) + 면접 초대 액션           │  
  ├─────┼──────────────────────────┼─────────────────┼────────────────────────────────────────────┤
  │ 10  │ /auth                    │ 로그인/회원가입 │ 사용자 인증 및 개인 데이터 연결            │
  └─────┴──────────────────────────┴─────────────────┴────────────────────────────────────────────┘  
  
  ---                                                                                                
  각 화면의 역할은 다음과 같습니다.                               
                                                                                                     
  1. 랜딩                                                         
  - 서비스 첫 인상을 결정하는 진입 화면                                                              
  - 구직자/기업 양면 가치를 한눈에 전달                                                              
  - 구직자 → /jobs, 기업 → /employer 분기 허브                                                       
                                                                                                     
  2. 공고 탐색                                                                                       
  - 구직자가 가장 자주 사용하는 핵심 화면                                                            
  - 매칭 스코어 게이지 + 스킬 배지로 클릭 전 적합도 판단 (F-01)                                      
  - 경력 레벨 태그 필터(F-02) + 문화 태그 필터(F-05)로 정밀 탐색                                     
  - A/B 테스트 E1 실험이 적용되는 화면                                                               
                                                                                                     
  3. 공고 상세                                                                                       
  - 구직자 의사결정이 발생하는 전환 핵심 화면                                                        
  - 사이드 패널로 합격자 평균 vs 내 프로필 갭 시각화 (F-03)                                          
  - AI 탈락 사유 시뮬레이션으로 지원 전 부족 요소 사전 확인 (F-03)
  - 문화 태그 + 재직자 평점 표시 (F-05)                                                              
  - "지원하기" 또는 "보완 후 재도전" 분기                                                            
                                                                                                     
  4. 구직자 프로필                                                                                   
  - 구직자의 커리어 자산을 구조화하는 화면                                                           
  - 프로젝트 카드 최대 5개 등록으로 추천 가중치 반영 (F-04)                                          
  - 목표 직무 기반 역량 진단 + 보완 우선순위 2~3개 제시 (F-15)    
  - 이력서 모호한 표현 탐지 + 개선 예시 제공 (F-16)                                                  
                                                                                                     
  5. 마이페이지                                                                                      
  - 구직자 활동 이력을 한눈에 확인하는 화면                                                          
  - 지원한 공고 상태 추적 (서류 접수/검토 중/결과)                                                   
  - 저장한 공고 관리                                              
  - 역량 진단 이력 비교 (이전 vs 현재 진단 결과)                                                     
                                                                  
  6. 초기 설정                                                                                       
  - 가입 직후 1회 진행하는 온보딩 화면                            
  - 역할 선택: 구직자 → 목표 직무 + 스킬 + 경력 입력 / 기업 → 회사 정보 + 채용 포지션                
  - 구직자: 첫 역량 진단(F-15) 트리거, 추천 알고리즘 초기화                          
  - 기업: 첫 공고 등록(F-05 문화 태그 포함) 유도                                                     
                                                                                                     
  7. 기업 대시보드                                                                                   
  - 기업 HR이 지원자를 관리하는 핵심 화면                                                            
  - 적합/검토필요/미충족 3단계 자동 분류 탭 (F-06)                                                   
  - Skill-Fit Score 0~100점 + 근거 요약 (F-06)                                                       
  - 리스크 포인트 "확인 필요" 배지 표시 (F-17)                                                       
                                                                                                     
  8. 공고 등록                                                                                       
  - 기업이 채용 공고를 작성하고 조건을 설정하는 화면                                                 
  - JD 입력 + 필수 조건(최소 경력, 필수 스킬, 자격증) 설정                                           
  - 문화 핏 태그 최대 5개 선택 (F-05)                                                                
  - 등록 완료 시 자격요건 자동 필터링(F-06) 활성화                                                   
                                                                  
  9. 지원자 상세                                                                                     
  - 개별 지원자를 심층 검토하는 화면                              
  - Skill-Fit Score 상세 분석 (프로젝트별 기술 매칭 근거)                                            
  - 리스크 포인트 개별 확인/완료 처리 (F-17)                      
  - 면접 초대 / 보류 / 불합격 액션 수행                                                              
                                                                                                     
  10. 로그인/회원가입 페이지                                                                         
  - 사용자 식별 및 데이터 연결                                                                       
  - 개인화 기능 활성화 진입점                                                                        
  - 가입 완료 시 /onboarding으로 자동 이동

  서비스 흐름은 다음과 같이 구성됩니다.                                                              
                                                                                                     
  구직자 흐름:                                                                                       
  "랜딩 진입 → 가입/로그인 → 온보딩(직무·스킬 설정) → 공고 탐색(스코어 확인) → 공고 상세(역량        
  리포트·AI 시뮬레이션) → 지원 또는 프로필 보완 → 마이페이지(결과 확인)"                             
                                                                                                     
  기업 흐름:                                                                                         
  "랜딩 진입 → 가입/로그인 → 온보딩(회사 정보) → 공고 등록(JD·조건·문화 태그) → 대시보드(자동
  분류·Skill-Fit) → 지원자 상세(리스크 확인) → 면접 초대
